# 🎨 Mini Projetos Front-End

Repositório criado para armazenar pequenos projetos e exercícios de **Front-End**, desenvolvidos durante meus estudos e práticas de programação.

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript

## 📁 Projetos

Os projetos estão organizados de acordo com o nível e as tecnologias utilizadas:

### 🖥️ HTML + CSS

Mini projetos focados na criação e estilização de interfaces, como:

* Landing Pages
* Telas de login
* Cards
* Formulários
* Menus
* Interfaces responsivas
* Componentes visuais

### ⚡ HTML + CSS + JavaScript

Projetos que, além da interface, possuem interações e funcionalidades utilizando JavaScript, como:

* Calculadoras
* Listas de tarefas
* Validações de formulários
* Menus interativos
* Contadores
* Pequenas aplicações web

## 🎯 Objetivo

Este repositório tem como objetivo registrar minha evolução no desenvolvimento Front-End, praticar conceitos e criar uma coleção de pequenos projetos para compor meu portfólio.

## 📌 Observação

Os projetos são independentes e possuem diferentes níveis de complexidade. Novos projetos serão adicionados conforme meu aprendizado.
